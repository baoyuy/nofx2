# 爆发榜回放校准结果

- 日期：2026-11-14
- 数据：2026-10-20 ~ 2026-11-14，25 天请求窗口、27 个有效交易日
- 范围：200 个流动性最好的 U 本位永续，53 个日涨幅 ≥20% 的候选，3021 条小时样本
- 工具：`go run ./cmd/explosive_backtest -days 25 -min-gain 0.2 -max-symbols 200 -rps 1.5`

## 一、先修正评估方法

第一版用"入场到当日收盘的剩余涨幅"做标签，发现有时间偏差：越晚入场剩余收益机械性越高（04:00 −4.05%，20:00 +0.88%），因为暴露时间更短。

改用**同小时超额**：每条样本减去"同一天同一小时所有候选的平均剩余"，再去掉大盘当日漂移。

## 二、总体收益

| 指标 | 数值 |
|---|---|
| 平均剩余收益 | −0.59% |
| 中位数剩余收益 | −1.79% |
| 上涨比例 | 41% |
| 涨幅 ≥+10% 的比例 | 16.4% |

在"当日涨过 20% 的币"里随机选一个持有到收盘，期望是**亏的**。这符合"追涨"的直觉风险。

## 三、当前线上公式的表现

| 指标 | 数值 |
|---|---|
| 日级 IC（对上证超额） | −0.068（训练期 −0.093） |
| 前 3 名命中 +10% 的比例 | 24.7%（基准 16.4%） |
| 前 3 名中位超额 | −0.36% |
| 前 3 名平均超额 | +1.90%（被少数大涨样本拉高） |

**关键发现：排序不是"预测准"，而是"筛出了高波动币"。**

每小时取前 3 个不同币（918 次）：

| 策略 | P(再涨≥20%) | P(再涨≥50%) | P(跌≥15%) | 中位剩余 |
|---|---|---|---|---|
| 全部候选（基准） | 8.5% | 2.4% | 13.4% | −1.79% |
| 当前公式前 3 | **13.6%** | **4.7%** | 17.0% | −0.85% |
| 只按今日涨幅前 3 | **14.2%** | **4.8%** | 18.6% | −1.75% |
| 只按 OI 前 3 | 10.7% | 2.6% | 14.3% | −1.36% |
| 只按今日涨幅最低前 3 | 5.4% | 0.4% | 6.6% | −1.21% |

读法：

- 当前公式确实把"大涨概率"从 8.5% 提到 13.6%、"涨 50%"从 2.4% 提到 4.7%，约 **1.6~2 倍**。
- 但代价是回撤概率也从 13.4% 升到 17.0%。
- **"只按今日涨幅排序"几乎同样有效**（14.2% / 4.8%），说明当前公式的额外因子（OI、量能斜率、结构）对"抓大涨"贡献很小。
- 反过来"买涨幅最低的"几乎没有大涨机会（5.4%），此前"低涨幅更好"的 IC 只是中位数意义上的避险，不是抓爆发。

## 四、单因子 IC（对同小时超额，分日平均）

| 因子 | IC | 稳定性（奇偶日/前后半） |
|---|---|---|
| 今日涨幅（取负） | +0.104 | 稳定 |
| OI 1h 变化 | +0.059 | 不稳（0.01 / 0.11） |
| 资金费率 | +0.034 | 弱 |
| 量能斜率 | +0.038 | 弱 |
| ATR | −0.092 | 稳定为负（高波动反而差） |
| 规模（成交额对数） | −0.129 | 稳定为负（小币更好） |

注意：IC 是秩相关，看重"中位数/排序"，与"抓尾部大涨"不是一回事。这也是为什么 IC 为负的当前公式，却在 P(+20%) 上有正贡献。

## 五、结论

1. **没有任何特征能可靠预测"哪个币会暴涨"**。25 天数据里，最好的单因子也只有 0.1 量级的秩相关。
2. **当前榜单的价值在于"筛高波动"，不是"预测方向"**：大涨概率约 1.6~2 倍于随机，同时回撤概率也高约 1/4。
3. 若要"抓暴涨"，`今日涨幅`本身就是很强的因子，复杂公式没有明显增益；复杂因子的作用是**略微改善中位结果**（−0.85% vs −1.75%）。
4. 只能说明"候选池"，不能说明"该买"。

## 六、后续建议

1. **产品表述**：把榜单定位为"高波动观察池"，并在页面直接标注实测概率（P(+20%)≈14%、P(≤−15%)≈17%），不要用"预测剩余"这种暗示精确的词。
2. **准确率面板加尾部指标**：P(+20%)、P(+50%)、P(≤−15%) 比"平均超额"更贴近用户的问题；平均超额会被极少数样本主导。
3. **优化目标改写**：不要最大化平均超额，改为"在回撤约束下最大化 P(+20%)"，并对样本做 bootstrap 置信区间。
4. **补数据**：25 天远不够；币安 OI 只保留 30 天，若要更长历史需自行落库积累（线上已经在记）。
5. **暂不改线上权重**：现有公式在 P(+20%) 上并不比"按涨幅排序"差，改动没有数据支持。

## 七、运维记录

- 回放与线上共用服务器出口 IP。首次运行未限速，触发币安 418，IP 被封约 25 分钟，线上短暂受影响。
- 现默认 `-rps 2`，遇到 418 立即中止并提示。
- 跑大回放前应停掉本地容器（`docker compose stop`），减少共用 IP 的压力。

# 追加：抓妖币（点火型）回放验证

- 日期：2026-11-14 晚
- 目标：日涨幅 ≥50% 算"妖币"；要求在点火时（涨幅还 <20%）发现
- 数据：150 个流动性最好的永续（**全宇宙，含从未大涨的币**，用于统计假信号）
- 样本：4786 条小时记录、22 个交易日
- 工具：`go run ./cmd/explosive_backtest -days 20 -universe all -min-row-gain 0.03 -max-symbols 150 -rps 1.5`

## 基础概率

| 指标 | 数值 |
|---|---|
| 全样本最终涨 ≥50% | 5.0% |
| 早期（涨幅<20%、前 10 小时） | **2.7%** |
| 每天真正达到 ≥50% 的币 | **约 1.5 个** |

也就是说：**22 天里全市场只出现 33 次"日涨 50%+"**。

## 特征有效性（早期样本，预测最终 ≥50%）

| 特征 | 结论 |
|---|---|
| **成交量突增（15m 成交额 / 7 天中位）** | **唯一有效**，20 倍以上档命中 8.9%，0–2 倍档 1.8% |
| ATR（波动率） | 有效，与成交量突增效果相当 |
| 持仓量 1h 增加 | 弱正 |
| **突破 7 天最高价** | **反向**（0.3x），已经突破的币反而更差 |
| **长期横盘收窄（compress_7d）** | **反向**（0.3x），越窄越差 |

后两项与直觉相反，是这次回放最有价值的发现：**"刚突破 7 天高点"不等于妖币起点，往往已经是尾声**。

## 具体规则实测（每天最多 10 个候选，22 天）

| 规则 | 每天候选 | 命中 ≥50% | 命中 ≥100% | 有命中的天 |
|---|---|---|---|---|
| vol≥3 | 6.3 | 6.1% | 0.8% | 7/21 |
| vol≥3 且 ATR>1% | 5.1 | 7.4% | 0.9% | 7/21 |
| **vol≥2 且 ATR>1% 且 OI>0** | **4.5** | **8.4%** | **1.1%** | **7/21** |
| 基准（随机挑） | — | 2.7% | — | — |

## 结论

1. **点火信号真实存在，但很弱**：最好规则 8.4% 命中，是随机的 3.1 倍。
2. **三分之二的日子一个都不中**（7/21 天有命中）。
3. 若要每天 10–20 个候选，命中率会稀释到 5–6%。
4. 这本质是**彩票筛选器**：约 12 个候选里出 1 个日涨 50%+，另 1/12 概率日涨 100%+。
5. 突破/横盘收窄这两个"教科书形态"在这个市场里没有正向作用，不要用。

## 建议的产品形态

- 定位：**点火观察池**，每 5–15 分钟扫全市场，列出"成交量突增 + 高波动 + 持仓量增加"的币
- 明确标注实测概率（约 8% 日涨 50%），不要暗示"预测"
- 每天 5–10 个，宁缺毋滥；空榜是常态
- 不与现有"今日涨幅榜"混在一起——两者逻辑相反
